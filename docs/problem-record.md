## 2026-08-27 Playwright MCP 未能进入 OpenCode 会话

- 问题：探索失败说明为「当前会话未提供 Playwright MCP 浏览器工具」。日志里 MCP 在约 1.5 秒后 `server unavailable`。

- 经验：MCP 启动参数必须能在本机单独跑通；模型输出的探索失败不能覆盖宿主已经看到的工具进程失败。

## 2026-08-27 解析失败步骤从表中消失，Excel 行号被当成步骤序号

- 状态：已解决
- 问题：填写/选择/检查文本缺数据时，该行不进入 `steps`。审阅页表格「序号」用的是步骤序号，报错「第 N 行」用的是 Excel 行号。用户文件中「步骤」第 7 行是填写取样人，第 8 行才是点击保存；失败行被隐藏后，表格只剩序号 7 的点击保存，看起来像点击也要填数据。
- 处理：字段错误仍保留可识别步骤；报错补充步骤序号和动作对象；表格列名改为「步骤序号」。
- 经验：Excel 行号和步骤序号必须同时出现在用户可见文案里，失败行不能从审阅表里拿掉。

## 2026-08-27 Excel 日期单元格被读成序列号或 ISO 时间

- 状态：已解决
- 问题：步骤「数据」里的日期，有的被 Excel 存成序列号（如 `46262`），有的被读成 `2026-08-28T00:00:00.000Z`，不是页面上看到的选项文字。
- 处理：解析把日期单元格转成 `2026-08-28` 这种日历文字；导入模板「数据」列设为文本格式，避免 Excel 自动改成日期类型。
- 经验：给探索用的数据必须是页面选项文案。日期类型单元格不能直接 `toISOString()`。

## 2026-08-27 页面探索超时且没有任何 OpenCode 日志

- 状态：已解决
- 问题：重试后满 180 秒只显示「页面探索超时」。诊断目录里 stdout/stderr 为空，MCP 也没有产物。探索提示里的地址被拼成 `http://10.82.7.5/web/IMQM14`，丢掉了环境路径 `/xmdmpms-imms-f`。同时超时用强制杀进程，管道里未刷新的输出也会丢失。页面只有按钮转圈，看不出后台是否在工作。
- 处理：探索地址改用 `buildStartUrl`；OpenCode 打开 `--print-logs` 并在收到输出时立即落盘；超时文案带上最后事件或「没有输出」；重试期间轮询状态并显示已等待时间。
- 经验：带路径前缀的环境地址不能用 `new URL(path, base)` 拼接。长耗时任务必须把过程日志即时写盘，并在页面上显示等待时间。

## 2026-08-27 离开任务详情会取消正在进行的页面探索

- 状态：已解决
- 问题：审阅和重试把探索绑在当前 HTTP 请求上。用户等待时离开页面，连接断开后探索被取消或看起来像卡住。
- 处理：审阅/重试启动后台作业后立即返回；同一任务同时只跑一个探索作业；详情页轮询状态。离开页面只停止轮询。
- 经验：长耗时探索不能绑在浏览器请求的生命周期上。

## 2026-08-27 打开导入任务详情立即报「页面探索已取消」

- 状态：已解决
- 问题：Excel 解析成功后详情页会自动 POST `/review`。取消信号听的是请求 `close`，请求体读完就会触发，客户端还在等响应，探索已被当成取消。
- 处理：改为监听响应 `close`，与运行接口一致；客户端未断开时不取消。
- 经验：长耗时接口的取消要绑在响应连接上，不能绑在请求流结束上。
