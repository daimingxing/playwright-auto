# Triage Labels

工程技能使用以下 canonical triage roles；右侧为本仓库 GitHub Issues 中使用的标签。

| 角色 | 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给自动化智能体实现 |
| `ready-for-human` | `ready-for-human` | 需要人工实现 |
| `wontfix` | `wontfix` | 不处理 |

工程技能提到上述角色时，使用对应标签。
